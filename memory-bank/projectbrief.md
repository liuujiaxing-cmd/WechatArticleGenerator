# 项目简报 (Project Brief)

## 核心需求
- [x] 创建一个基于 Python 的工具，用于生成微信公众号文章。
- [x] 集成 LLM（兼容 OpenAI 接口）进行内容生成。
- [x] 支持多种文章类型/语调（热点、AI 新闻、生活感悟、文化历史等）。
- [x] 生成兼容微信渲染引擎的 HTML 输出（基于表格布局）。
- [x] 实现“安全检查”机制，确保内容合规。
- [x] 创建专用的 Agent Skill (`wechat-article-writer`) 以供未来复用。

## 目标
- 自动化微信公众号的内容创作流程。
- 确保输出高质量、引人入胜且格式精美的文章，尽量减少人工编辑。
- 为添加更多内容源（如实时网络搜索）和功能提供可扩展的基础。
