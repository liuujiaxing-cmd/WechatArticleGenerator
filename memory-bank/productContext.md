# 产品背景 (Product Context)

## 问题陈述
微信公众号的内容创作者经常面临以下挑战：
1.  **写作瓶颈**：难以持续发现热点话题并撰写引人入胜的内容。
2.  **排版痛苦**：微信编辑器需要特定的 HTML 结构（通常基于表格）才能美观且跨设备兼容。
3.  **合规风险**：确保内容不违反平台规则或法律法规。

## 核心功能
1.  **全自动生成流程**：
    - 输入：简单的话题（Topic）和类型（Type）。
    - 过程：RAG 搜索 -> AI 写作 -> AI 配图 -> CSS 排版 -> 上传素材。
    - 输出：微信公众号草稿箱中的完整文章（含封面、配图、二维码）。
2.  **多维风格矩阵**：
    - **内容风格**：
        - `zhihu_real`: 现实主义知乎风（扎心、清醒、反内卷）。
        - `hot_topic`: 紧跟时事的热点风。
        - `life`: 温暖治愈的生活风。
    - **视觉风格**：
        - `Industrial Retro`: 工业冷淡风（等宽字体、方框、黑白灰）。
        - `Bubble`: 气泡风（圆角、高亮、年轻化）。
        - `Modern/Classic`: 经典/极简商务风。
3.  **微信原生兼容**：
    - 深度适配微信 HTML 渲染规则，确保在手机端完美显示。
    - 自动处理图片上传和 URL 替换。

## 写作规范 (Writing Standards)
- **核心技巧**：
    1.  **标题决定生死**：反差、利益前置、数字具象、私密感。
    2.  **黄金3秒开头**：结论先行、共情场景、争议观点。
    3.  **滑梯模型 (Slide Effect)**：段落钩子、SCQA 模型。
    4.  **社交币属性**：金句替嘴、稀缺价值、价值观共鸣。
    5.  **临门一脚 (结尾)**：互动提问、惊喜彩蛋、人设碎碎念。
- **排版要求**：
    - 去除正文中的标题和作者显示（由微信原生功能接管）。
    - 作者统一署名：“伊扎里斯的索拉尔”。
    - 增强 HTML 排版：支持层级 (H2/H3)、引用 (Blockquote)、居中、加粗、斜体。

## 目标受众
- 微信公众号运营者。
- 社交媒体营销人员。
- 内容聚合平台。
